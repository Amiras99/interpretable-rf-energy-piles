# Interpretable Random Forest Modeling of Interaction Factors in Energy Pile Groups

This repository contains the Python source codes used in the study:

**Interpretable Random Forest Modeling of Interaction Factors in Energy Pile Groups**

The codes implement the statistical analysis, exploratory data visualization, Random Forest surrogate modelling, model evaluation, feature-importance analysis, SHAP-based model interpretation, Sobol global sensitivity analysis, and response-surface analysis presented in the study.

## Repository Structure

```text
interpretable-rf-energy-piles/
│
├── README.md
├── requirements.txt
│
├── code/
│   ├── descriptive_statistics.py
│   ├── pairplot.py
│   └── rf_surrogate_analysis.py
│
├── data/
│   └── README.md
│
└── results/
    └── README.md
```

### `code/`

This directory contains the Python scripts used for the analyses:

* `descriptive_statistics.py` — computes descriptive statistics for the main numerical variables.
* `pairplot.py` — generates pairwise plots to visualize the relationships among the main variables and pile-group configurations.
* `rf_surrogate_analysis.py` — performs Random Forest surrogate modelling, hyperparameter optimization, model evaluation, permutation feature-importance analysis, SHAP analysis, Sobol sensitivity analysis, and response-surface analysis.

### `data/`

The dataset used in the study is **not included in this repository** because it is not authorized for public redistribution.

Users with authorized access to the dataset can provide the required `data.csv` file locally and specify its location when prompted by the scripts.

### `results/`

This directory is reserved for analysis outputs generated by the Python scripts. The generated results are not included in the repository by default.

* Python 3.13.9
* NumPy 2.3.4
* pandas 2.3.3
* Matplotlib 3.10.6
* Seaborn 0.13.2
* scikit-learn 1.7.2
* joblib 1.5.2
* SHAP 0.50.0
* SALib 1.5.2

The required Python packages are also listed in `requirements.txt`.

## Input Data

The scripts require a CSV file named:

```text
data.csv
```

The dataset contains the variables used for the analyses reported in the study, including:

* `Days`
* `Pile_Group`
* `S/D`
* `L/D`
* `IF`

Because the dataset is subject to data-access restrictions, it is not distributed with this repository.

To use the scripts, users with authorized access to the dataset should provide the location of the folder containing `data.csv` when prompted by the relevant scripts.

## Running the Code

### 1. Set up the Python environment

A Python environment compatible with the versions specified in `requirements.txt` is recommended.

Install the required packages using:

```bash
pip install -r requirements.txt
```

### 2. Prepare the input data

Place the authorized `data.csv` file in a local directory accessible to the user.

The dataset should retain the variable names and structure required by the scripts.

### 3. Run the scripts

Navigate to the `code/` directory and run the desired script.

For example:

```bash
python descriptive_statistics.py
```

```bash
python pairplot.py
```

```bash
python rf_surrogate_analysis.py
```

When prompted, provide the path to the directory containing `data.csv`.

## Analyses Included

The provided scripts cover the following analyses:

1. Descriptive statistical analysis.
2. Pairwise exploratory visualization.
3. Random Forest surrogate modelling.
4. Hyperparameter optimization using `GridSearchCV`.
5. Model-performance evaluation using R², RMSE, MAE, and SMAPE.
6. Permutation feature-importance analysis.
7. SHAP-based model interpretation.
8. Sobol global sensitivity analysis.
9. Response-surface analysis.
